Build an HTML gallery of everything generated by this plugin: $ARGUMENTS

Use the `gallery` MCP tool. It scans the image/audio/video output directories,
reads each file's `.regenerate.json` sidecar, and writes a self-contained
`gallery.html` with a thumbnail grid — each card showing the prompt, model,
tier, params, **cost**, and date, plus client-side filter / search / sort.

- Default scope is **all modalities**. Narrow with `modality` (`image` / `tts` /
  `video`) or `provider` / `model` if the user asks (e.g. "just the gpt-image-2 ones"
  → `provider: "openai"`, `model: "gpt-image-2"`).
- Thumbnails need `sharp` (video posters also need `ffmpeg`); the tool degrades
  gracefully and notes if either is missing.
- The gallery is regenerated fresh each run — re-run it to pick up new outputs.

After building, give the user the file path and the `file://` URL to open it,
and mention the item count + total cost the tool reports. Pass `open: true` only
if the user wants it opened automatically.
