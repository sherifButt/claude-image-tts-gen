what a thin wrapper leaves on the floor

Six things most provider wrappers don't ship.

Plenty of MCP servers wrap a vendor. genkettle wraps six and adds the cross-cutting work that, without it, lands on you: budgets, ledger, sidecars, failover, chunking, batch.

№ 01

Cost-aware before the call.

Per-call, session, and per-project ledgers. Hard daily/weekly/monthly caps enforced pre-call, not after the charge. Dry-run estimate_cost ranks every provider/tier combo. A $0 cache returns identical repeats for free.

№ 02

Reproducibility built into the file system.

Every output writes a hidden .regenerate.json sidecar with prompt, provider, model, tier, params, lineage. regenerate re-runs the brief; iterate adds a tweak and threads parent → child. Prompts never get lost in chat history.

№ 03

Long-text TTS, chunked when it has to be.

Sentence-aware splitter, ffmpeg stitch, single deliverable. Triggers pre-emptively when the text exceeds the slot's max chars, and reactively when a provider rejects a shorter input as too long — INPUT_TOO_LONG retries on the same provider so voice and cache stay stable.

№ 04

Provider failover, with a paper trail.

Automatic on rate-limit, 5xx, or timeout. Each retry logs its cost delta. Voice cloning pins to the preferred provider so the reference isn't silently dropped when a backend without cloning would have otherwise been chosen.

№ 05

Free local escape hatch.

Same plugin, same skills, same sidecars, no API key, no network, no bill. Route to Kokoro-FastAPI, Speaches, Orpheus-FastAPI, Chatterbox, or Voicebox. The local provider is a first-class citizen — auto-detected at startup since v0.8.5.

№ 06

MCP-native UX you'd expect.

Elicitation when ≥2 prompts queue (batch vs. sync). Sampling for the prompt rewriter. Notifications on batch completion. Resources for recent outputs in the asset panel. Structured errors with code, message, suggestedFix — no raw provider blobs.

$0 / call

Run it 100% local. Zero API keys.

Point genkettle at any OpenAI-compatible local server and generate images or speech without a key, network round-trip, or dollar spent. Sidecars, cache, regenerate, iterate, post-processing — everything keeps working.

The local provider is auto-detected at startup since v0.8.5 — if LOCAL_BASE_URL/models responds, it joins the failover chain automatically. Set LOCAL_ENABLED=false only if you need to force-exclude a reachable server.

install

Two commands. No clone, no build.

Inside an existing Claude Code session. The plugin registers slash commands and MCP tools automatically on enable.

step 01 · marketplace

Add the marketplace and install.

You'll get the slash commands (/gen-image, /gen-speech, /gen-cost, /gen-budget, …) and the MCP tool surface in one go.

claude code 
/plugin marketplace add sherifButt/claude-image-tts-gen
/plugin install claude-image-tts-gen@claude-image-tts-gen-marketplace
step 02 · configure

Export at least one key, or run a local server.

Grab a free Gemini key at aistudio.google.com/apikey. Append to ~/.zshrc for persistence — new terminals + sessions inherit it.

~/.zshrc 
# required: at least one provider key OR a local server
export GEMINI_API_KEY='your-key'
export OPENAI_API_KEY='your-key'

# optional: per-provider default voices (saves --voice each call)
export GEMINI_DEFAULT_VOICE=Charon
export OPENAI_DEFAULT_VOICE=onyx
export ELEVENLABS_DEFAULT_VOICE='<voice-id>'

# optional: local server (auto-detected since v0.8.5)
export LOCAL_BASE_URL=http://localhost:8880/v1
