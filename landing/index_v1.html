why this MCP is different

One knob spans every provider. Cost-aware from the first call.

01

One knob per call

small | mid | pro spans every provider. Code written for Gemini runs unchanged against OpenAI or a local Kokoro model — swap --provider and the call still works. No per-vendor quirks in your prompt code.

02

Cost-aware, pre-call

Per-call, session, and per-project ledgers. Hard daily/weekly/monthly caps enforced before you spend. Dry-run estimate_cost ranks every provider/tier combo. A $0 cache for identical repeats.

03

Reproducibility built in

Every output gets a hidden .regenerate.json sidecar with prompt, model, tier, params, lineage. regenerate re-runs it; iterate threads parent → child. Prompts never get lost in chat history.

04

Cross-cutting work, once

Provider failover with logged cost delta. Batch mode where the vendor offers it. Long-text TTS auto-chunked at sentence boundaries — including reactive chunking when a provider rejects a single call as too long.

05

Free local escape hatch

Same plugin, same skills, same sidecars, no API key, no network, no bill. Route to Kokoro-FastAPI, Speaches, Orpheus, Chatterbox, or Voicebox. The local provider is a first-class citizen, not a bolt-on.

06

MCP-native UX

Elicitation when ≥2 prompts queued. Sampling for prompt rewrites. Notifications on batch completion. Resources for the asset panel. Structured errors everywhere — no raw provider blobs.

$0 / call

Run it 100% local. Zero API keys.

Point genkettle at any OpenAI-compatible local server and generate images or speech without a key, network round-trip, or dollar spent. Sidecars, cache, regenerate, iterate, post-processing — everything just works.

The local provider is auto-detected at startup since v0.8.5 — if LOCAL_BASE_URL/models responds, it joins the failover chain automatically.

Kokoro-FastAPI Voicebox
shell 
# start a local TTS backend (example: Kokoro)
docker run -p 8880:8880 \
  ghcr.io/remsky/kokoro-fastapi-cpu:latest

# auto-detected on startup, but you can confirm
node mcp-server/dist/cli.js --check-local

# generate against the local server
node mcp-server/dist/cli.js --speech \
  -p "hello world" \
  --provider local --model kokoro

install

Two commands inside Claude Code. No clone, no build.

marketplace

Add the marketplace and install the plugin.

The plugin registers slash commands (/gen-image, /gen-speech, …) and MCP tools automatically on enable.

claude code session 
/plugin marketplace add sherifButt/claude-image-tts-gen
/plugin install claude-image-tts-gen@claude-image-tts-gen-marketplace
configure

Export at least one API key, or run a local server.

Grab a free Gemini key at aistudio.google.com/apikey. Add to ~/.zshrc for persistence across sessions.

~/.zshrc 
# required: at least one provider key OR a local server
export GEMINI_API_KEY='your-key'
export OPENAI_API_KEY='your-key'

# optional: per-provider default voices
export GEMINI_DEFAULT_VOICE=Charon
export OPENAI_DEFAULT_VOICE=onyx
